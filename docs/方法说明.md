# 方法说明与判定口径

## 一、核验流程（可复现）

```
AI 生成参考文献
      │
      ├─ 有 DOI ──→ Crossref /works/{doi} ──→ 200 = 属实，404 = 虚构
      │
      ├─ 无 DOI（外文）──→ Crossref query.title（取前 5 条里最相似）
      │                         └─ 题名相似度 ≥55% 疑似属实；35~55% 存疑；<35% 疑似虚构
      │
      ├─ 中文条目 ──→ 浏览器插件按「篇名」检索知网 ──→ 命中 / 部分命中 / 疑似虚假
      │                         └─ 或人工导出题录 → 题录比对
      │
      └─ 网络失败 ──→ 标记「查询失败」，不计入统计，重试
```

## 二、题名抽取规则

一条参考文献最容易被搞错的是「哪一段才是题名」。抽取顺序：

1. `**粗体**` 包裹的内容
2. `《书名号》` 或 `"引号"` 包裹的内容
3. GB/T 7714：`作者. 题名[J]. 刊名, 年, 卷(期): 页` → 取 `[J]` 之前、第一个句点之后
4. 英文 `Authors. Title. Journal, Year` → 按句点切段，跳过人名段和刊名段
5. 中文条目：切掉 `本文/该文/研究表明/综述了…` 之后的概述部分，再按长度兜底截断

抽错可以在界面里直接改题名再「重搜」，不必重跑整段。

## 三、相似度怎么算

- 先归一化：小写、去掉标点与多余空白，只保留字母数字和汉字
- 取最长公共子串对命中题名的覆盖率，再乘 0.8，加长度比 0.2
- 命中题名明显短于输入（<55% 长度）时再压分——防止 `Perovskite quantum dots` 这种短标题蹭分

## 四、人机分工（写进作品时可讲）

| 环节 | 机器做 | 人做 |
|---|---|---|
| 抽取 | 从参考文献里找题名 | 抽错时改正 |
| 初筛 | DOI 解析、开放库检索、相似度 | —— |
| 中文 | 插件批量检索、命中数统计 | 登录知网、过验证 |
| 判定 | 给分级与证据 | 对「存疑」下最终结论 |
| 汇总 | 导出 CSV / 打印报告 | 解释口径、写反思 |

> 工具明说自己哪里不可靠（中文覆盖、无 DOI 无法证明），并把判断交回给人——
> 这一条本身就是信息素养的落点。

## 五、参考的已有工作

- HalluCitation（arXiv:2601.18724）：300 篇被编造的 ACL 论文，量化虚假引用在学术传播中的影响
- CiteAudit（arXiv:2602.23452）：科学参考文献核验基准
- CiteCheck（arXiv:2605.27700）：基于检索溯源的引用幻觉检测
- Ji et al., Survey of Hallucination in Natural Language Generation（arXiv:2202.03629）

以上均为预印本，引用时请按规范标注 arXiv 与版本。

## 六、已知限制

1. Crossref 不覆盖中文期刊，中文命中率低；
2. 无 DOI 条目无法「证明」真伪，只能给疑似；
3. 知网/万方无公开 API，插件依赖用户浏览器里的登录态，且可能触发验证；
4. 页面结构变化会导致抓取失败，需要更新选择器。
