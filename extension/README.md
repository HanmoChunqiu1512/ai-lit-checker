# 插件使用说明（Edge / Chrome）

## 安装

1. Edge 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」，选择本文件夹（`extension`）

## 使用

1. 先登录知网（校园网 / 机构账号），能正常搜到结果
2. 点插件图标 → 「检测登录」，确认显示已登录
3. 粘题名（一条一行），或从核验器网页点「发到插件」自动带过来
4. 点「开始检索」，插件逐条按「篇名」检索（`korder=TI`）
5. 结果回填到核验器网页的「插件判定」列；插件里也能「导出结果」成 CSV

## 判定

| 情况 | 判定 |
|---|---|
| 结果里有同名题名 | 命中 |
| 命中数 > 阈值（默认 20） | 疑似虚假（命中过多，题名太泛或不存在） |
| 1 ~ 阈值 | 部分命中（需人工看） |
| 0 | 未命中（可能虚构） |

阈值在插件面板里可改。

## 遇到问题

- **显示“未登录或被重定向”**：浏览器没登录，或登录态还没生效。登录后点「继续」。
- **显示“被安全验证挡住”**：手动在打开的标签页里滑一下，回来点「继续」。
- **命中 0 条且没有报错**：可能页面结构变了，看插件列表里的「页面诊断」行数，
  必要时改 `background.js` 里 `collectInPage` 的选择器。
- **插件和网页连不上**：① 确认网页是 `http://127.0.0.1:8799`（用 `server/启动核验器.cmd` 打开）
  ② 在 `edge://extensions` 里点插件「刷新」③ 刷新网页。15 秒连不上页面右上角会列排查清单。

## 权限说明

- `tabs` / `scripting`：开关标签页、读取检索结果
- `storage`：保存队列进度（后台被回收也不丢）
- `host_permissions`：仅限知网、万方、本地核验器地址
