把 AI 生成的一段参考文献粘进来，逐条核验真伪：有 DOI 查 DOI，没有就用题名走 Crossref 书目检索。判定口径见页脚。
中文文献要两步才能自动核验：装浏览器插件（Edge / Chrome 通用）→ 在浏览器里登录知网
没装插件也能用自动核验，只是中文条目要点链接人工查。

两步开始用（Edge / Chrome 都一样）

用浏览器插件批量查中文

1. 装插件：解压「文献核验助手」压缩包，打开 edge://extensions（Chrome 是 chrome://extensions）， 打开「开发人员模式」，点「加载解压缩的扩展」，选解压出来的文件夹
2. 点插件图标，先点「检测登录」，确认已登录知网
3. 回到本页点「发到插件」，中文条目会自动推送过去（不用复制粘贴）
4. 插件逐条查完，结果会回填到下面表格的「插件判定」列
人工模式：粘贴知网/万方导出的题录（BibTeX、EndNote、GB/T 7714 都行），逐条比对
判定口径：DOI 能解析 → 属实；无 DOI 时按题名相似度，≥55% 疑似属实、35%~55% 存疑需人工判断、<35% 疑似虚构。
中文条目单独标记“需知网核验”，不计入虚构率——Crossref 基本不收录中文期刊，直接判虚构会误伤。
Crossref 对任何查询都会返回最相近的一条，所以“存疑”必须人工复核——这一步不能省。
核验数据来自 Crossref 公开 API，本页不上传、不保存任何内容。
